# Фотостудия «Объектив» — учебный проект (C# / WinForms / SQLite)

Тема: **Фотостудия — клиенты, съёмки, заказы, печать, оплата.**

## Запуск
1. Установи **.NET 8 SDK** и Visual Studio 2022 (нагрузка «Разработка классических приложений .NET»).
2. Открой папку проекта (или `PhotoStudio.csproj`) → дождись восстановления NuGet-пакета `Microsoft.Data.Sqlite` → **F5**.
3. При первом запуске БД `Data/studio.db` создаётся автоматически и заполняется тестовыми данными.

ФИО и группа уже указаны в `AppInfo.cs` (группа 22о, Василёнок Анастасия Михайловна) и показываются в окне «О программе / Контакты».

## Как объяснить палитру и шрифты (вопрос на защите)
- **Тёмная серо-синяя основа** (`#16171D`, `#22242E`) — как проявочная/студийная обстановка: фото на тёмном фоне выглядят лучше, глаза не устают.
- **Янтарный акцент** (`#F2A541`) — цвет света студийной лампы и «затвора»; используется для действий, заголовков таблиц, значений показателей.
- **Бирюзовый** (`#4FB0AE`) — вспомогательный, холодный контраст к янтарному (статусы «Выдан/Проведена»). Красный (`#E5584F`) — только для ошибок и долгов.
- Принцип: 60% тёмный фон / 30% поверхности / 10% акцент. Контраст светлого текста на тёмном фоне > 7:1.
- **Шрифтовая пара:** *Georgia* (антиква, для заголовков и цифр — «журнальный», фотографический характер) + *Segoe UI* (гротеск, для интерфейса и таблиц — максимальная читаемость). Серифный + гротескный шрифт — классическое контрастное сочетание. Оба есть в Windows.
- Ссылки из задания для обоснования: colorscheme.ru, fontjoy.com, mixfont.com.

## Git (покажи на защите историю, ветки, слияние, откат)
Историю коммитов должен создать ты сам — вот сценарий (5–8 осмысленных коммитов):

```bash
git init
git add .gitignore PhotoStudio.csproj Program.cs AppInfo.cs
git commit -m "Init: каркас проекта WinForms"
git add Db.cs Security.cs Repo.cs Models.cs
git commit -m "БД SQLite: схема, тестовые данные, хэширование паролей"
git add Theme.cs Anim.cs Controls.cs
git commit -m "Тема, анимированные кнопки и фон"
git add LoginForm.cs MainForm.cs HomePage.cs AboutForm.cs
git commit -m "Окна: вход, главное, о программе"

git checkout -b feature/crud            # ветка
git add Entities.cs EditForm.cs EntityPage.cs SearchPage.cs
git commit -m "CRUD, поиск, фильтры, валидация"
git checkout -b feature/reports master  # (или main)
git add CalcPage.cs ReportsPage.cs README.md
git commit -m "Калькулятор, отчёты, бэкап"

git checkout master                     # (или main)
git merge feature/crud                  # слияние
git merge feature/reports
git log --oneline --graph --all         # показать историю

# откат: «сломай» что-нибудь, закоммить, затем
git revert HEAD                         # безопасный откат коммитом
# или: git reset --hard HEAD~1          # жёсткий откат (только локально)

git remote add origin https://github.com/<логин>/PhotoStudio.git
git push -u origin --all
```

## Структура
- `Program.cs` — вход, цикл «логин → главное окно → выход».
- `Db.cs` / `Repo.cs` / `Security.cs` — данные и безопасность.
- `Entities.cs` + `Models.cs` — декларативное описание таблиц, форм и правил; `EntityPage` и `EditForm` строятся по ним (меньше повторяющегося кода).
- `Theme.cs`, `Anim.cs`, `Controls.cs` — оформление и анимации.
- `MainForm`, `HomePage`, `LoginForm`, `AboutForm`, `CalcPage`, `ReportsPage`, `SearchPage` — экраны.
